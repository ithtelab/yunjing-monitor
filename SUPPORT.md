# Support

Use the appropriate channel so requests can be handled efficiently:

- Bugs with reproducible behavior: GitHub Issues.
- Feature proposals: GitHub Discussions or a feature request issue.
- Vulnerabilities: private GitHub Security Advisory; see [SECURITY.md](SECURITY.md).
- Deployment questions: include the release version, operating system, installation method, reverse proxy, storage driver, and redacted logs.

Do not post administrator passwords, Agent tokens, GitHub tokens, private keys, raw databases, backups, or unredacted environment files.

This community project does not provide guaranteed response times or emergency production support.
