# 云镜监控宝塔部署

## 选择服务端文件

在服务器执行 `uname -m`：

- `x86_64`：使用 `bin/vps-server-linux-amd64`
- `aarch64`：使用 `bin/vps-server-linux-arm64`

把对应文件复制或重命名为项目根目录下的 `vps-server`，然后执行：

```bash
chmod +x vps-server
chown -R www:www /www/wwwroot/monitor-party
```

## 配置环境变量

复制 `deploy/server.env.example` 为项目根目录下的 `server.env`，修改域名、后台密码和随机密钥：

```bash
cp deploy/server.env.example server.env
openssl rand -hex 32
chmod 600 server.env
chown www:www server.env
```

`AUTH_SECRET` 和 `ADMIN_PASS` 必须替换，`PUBLIC_URL` 必须填写实际 HTTPS 域名。

## 宝塔 Go 项目

- 项目目录：`/www/wwwroot/monitor-party`
- 运行用户：`www`
- 项目端口：`3000`
- 启动命令：`set -a && . ./server.env && set +a && exec ./vps-server`

绑定域名并申请 SSL，反向代理目标设置为 `http://127.0.0.1:3000`。Nginx 代理需要保留 WebSocket：

```nginx
proxy_http_version 1.1;
proxy_set_header Host $host;
proxy_set_header X-Forwarded-Proto $scheme;
proxy_set_header Upgrade $http_upgrade;
proxy_set_header Connection "upgrade";
proxy_read_timeout 90s;
```

部署后检查：

- `/`：门面首页（启用时）
- `/monitor`：节点观测台
- `/admin`：管理后台

升级时只替换 `vps-server`，不要覆盖 `data/` 和 `server.env`。
