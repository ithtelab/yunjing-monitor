# 云镜监控 Docker 一键部署

Docker 部署不使用宝塔 Go 项目管理器，也不需要单独安装 Go。

## 方式 A：终端一键安装（推荐）

1. 宝塔应用商店安装「Docker 管理器」和 Compose。
2. 上传并解压完整包到 `/www/wwwroot/monitor-party`。
3. 在宝塔终端执行：

```bash
cd /www/wwwroot/monitor-party
chmod +x deploy/docker/install.sh
PUBLIC_URL=https://你的域名 sh deploy/docker/install.sh
```

脚本会：

- 识别 AMD64 / ARM64
- 生成 `.env`（密钥与后台密码）
- 构建镜像并启动容器

首次生成的后台密码**只显示一次**，请立刻保存。

## 方式 B：宝塔 Docker 管理器创建

若用面板「创建容器 / 编排」：

1. 解压后把**整个项目目录**作为 Compose 项目目录（不要只上传某一个 yaml 到临时目录）。
2. Compose 文件选项目里的 `docker-compose.yml`。
3. **不必再单独准备 docker.env**（旧版依赖它，已改为环境变量默认值）。
4. 建议在面板环境变量里改掉：
   - `AUTH_SECRET`（长随机串）
   - `ADMIN_PASS`（强密码）
   - `PUBLIC_URL=https://你的域名`
5. 数据目录挂载保持 `./data:/app/data`。

> 若面板报 `env file ... docker.env not found`：说明还在用旧 compose。请换本包内新版 `docker-compose.yml`（已去掉 `env_file`）。

## 宝塔反向代理

域名反代到：

```text
http://127.0.0.1:1314
```

WebSocket：

```nginx
proxy_http_version 1.1;
proxy_set_header Host $host;
proxy_set_header X-Forwarded-Proto $scheme;
proxy_set_header Upgrade $http_upgrade;
proxy_set_header Connection "upgrade";
proxy_read_timeout 90s;
```

## 常用命令

```bash
cd /www/wwwroot/monitor-party
docker compose ps
docker compose logs -f
docker compose restart
docker compose down
docker compose up -d --build
```

- 配置：项目目录 `.env`（权限 600）
- 数据：`data/`（升级时不要删）

## 排错：permission denied

日志若出现：

```text
open /app/data/server.json: permission denied
```

原因：数据目录挂载后属主仍是宝塔的 `www`/`root`，容器内进程需要可写。

**新包**镜像启动时会自动 `chown` 数据目录。若仍失败，在项目目录执行：

```bash
cd /www/wwwroot/monitor-party
mkdir -p data
# 直接放开写权限（最快）
chmod -R 777 data
# 或改成容器用户
docker run --rm -v "$PWD/data:/data" alpine:3.22 chown -R 10001:10001 /data

docker compose up -d --build --force-recreate
docker compose logs --tail=50
```

## 后台

- 地址：`https://你的域名/admin`
- 默认用户：`admin`（可用 `ADMIN_USER` 改）
- 密码：安装脚本打印，或 `.env` 里的 `ADMIN_PASS`
- 侧栏「站点内容」可编辑前台公告与更新日志
